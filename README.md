# Math Model Simulator
Own desktop application project for learning about math models.

App supports:
- choosing language (English and Russian are supported)

## Stack
Project created using:
- .NET 8
    - C# 12
    - Avalonia UI 11

## Structure
- \MathModelSimulator – main directory
    - \src – directory for actual app code
        - \MathModelSimulator.Application – core project, includes startup file, views and view models
